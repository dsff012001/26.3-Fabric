# Mods — Minecraft 26.3 Fabric

Place downloaded mod `.jar` files compatible with **Minecraft Java 26.3 + Fabric Loader** in your Minecraft instance's local `mods` folder.

This GitHub folder is a guide/placeholder; the mod binaries are not bundled here. Use the official version links in [mod-list.md](../mod-list.md) and verify that every file says both **26.3** and **Fabric**. Some mods require Fabric API or other dependencies.
