# Shader packs

Place shader-pack `.zip` files here for organization. In Minecraft, shader packs are usually loaded from the instance's local `shaderpacks` folder, using a compatible shader loader such as Iris for **Minecraft 26.3 + Fabric**.

Shaders are optional and can lower FPS. Check [mod-list.md](../mod-list.md) for the Iris download page and select the 26.3 Fabric build.
