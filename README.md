# Minecraft 26.3 Fabric — FPS & Optimization Pack

This repository organizes a client-side Fabric performance setup for **Minecraft Java Edition 26.3**.

## Folders
- `mods/` — mod download guide and compatibility notes
- `shaderpacks/` — folder for optional shader packs (requires compatible Iris)
- `resourcepacks/` — folder for resource packs
- `datapacks/` — folder for datapack downloads
- `mod-list.md` — recommended mods and official download pages

## Important
This repository contains documentation and folder placeholders, **not the actual mod `.jar` files**. Download the Fabric build specifically for Minecraft 26.3 from each project's official page and place the downloaded `.jar` files in your Minecraft instance's `mods` folder. Do not put shader packs, resource packs, or datapacks in `mods`.

Start with Sodium, Fabric API, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, More Culling, and BadOptimizations where a compatible 26.3 Fabric release is available. Add optional mods one at a time and test the game after each change.

See [mod-list.md](mod-list.md) for links and notes.
