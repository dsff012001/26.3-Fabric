# Minecraft Java 26.3 — Fabric FPS mod list

This list is specifically for **Minecraft Java 26.3 + Fabric**. On each Modrinth page, select/check both the **26.3** game version and **Fabric** loader before downloading. Use only files whose compatibility metadata matches both.

## Recommended FPS / performance mods
- **Sodium** — rendering and FPS: https://modrinth.com/mod/sodium/versions?loader=fabric&game_versions=26.3
- **Fabric API** — common dependency for Fabric mods: https://modrinth.com/mod/fabric-api/versions?loader=fabric&game_versions=26.3
- **Lithium** — game logic optimization: https://modrinth.com/mod/lithium/versions?loader=fabric&game_versions=26.3
- **FerriteCore** — reduces memory use: https://modrinth.com/mod/ferrite-core/versions?loader=fabric&game_versions=26.3
- **ImmediatelyFast** — rendering/UI optimizations: https://modrinth.com/mod/immediatelyfast/versions?loader=fabric&game_versions=26.3
- **Entity Culling** — avoids rendering hidden entities: https://modrinth.com/mod/entityculling/versions?loader=fabric&game_versions=26.3
- **More Culling** — additional culling optimizations: https://modrinth.com/mod/moreculling/versions?loader=fabric&game_versions=26.3
- **BadOptimizations** — miscellaneous optimizations: https://modrinth.com/mod/badoptimizations/versions?loader=fabric&game_versions=26.3

## Installation
1. Install Fabric Loader for Minecraft 26.3 and launch the Fabric profile once.
2. Download compatible **Fabric + 26.3** `.jar` files from the official pages above.
3. Put mod `.jar` files in the Minecraft instance's `mods` folder.
4. Start with Sodium, Fabric API, Lithium and FerriteCore, then add other mods one by one.
5. If the game crashes, remove the last mod added and check the mod's dependencies and game-version support.
